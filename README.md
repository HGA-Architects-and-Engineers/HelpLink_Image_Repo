# HelpLink_Image_Repo
Contains the images that are used for the HelpLink portal.

## Features
-  in this repo are named after the IDs from Knowledge Base categories that they are supposed to represent in helplink.
-  Fonts that are used in the custom Helplink frontend are stored here.
-  Icons that are used in the custom Helplin frontend are stored here.

## Development
When adding a new category to be viewable from the frontend solutions articles, an image corresponding to that category should be placed in the images folder and named after the category ID and be in PNG format.  The icons and fonts should not need to be touched.

# Deployment on our network
This repo is not deployed on our network.  The Helplink frontend uses a JSDelivr CDN to get these files and deploy them to the Helplink frontend.  Helplink is not stored on our network at all.
